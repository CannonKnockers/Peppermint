# Interface material textures

Generated with the built-in imagegen tool on 2026-09-08. These are original raster surface assets for the whole GTK interface. `theme.css` layers tint and contrast over them; the images are bundled in the Python wheel and require no network at runtime.

Material placement: earth on the window and stop/deny controls, metal on the title bar/composer/assistant messages/entries, wood on conversation cards and choices, and bone on user messages/approval panels/primary controls.

Exact generation prompts follow.

## metal

File: `metal.png`

Use case: photorealistic-natural. Asset type: seamless material texture for a small desktop application button background. Primary request: Dark neutral graphite brushed metal, fine horizontal machining lines, subtle natural wear, a few tiny irregular scratches. Mid-dark cool grey, almost no saturation. Composition: square 1024 by 1024 image, orthographic close-up, material fills every pixel edge to edge, uniform scale and focus, no perspective. Soft completely even diffuse lighting, low local contrast so overlaid UI text remains legible. Photorealistic tactile surface, recognizable material grain, not a flat digital gradient. Seamlessly tileable at every edge. No text, labels, buttons, borders, bevels, frames, objects, logos, watermark, vignetting, hard shadows or large isolated features. This is only a raw surface texture.
